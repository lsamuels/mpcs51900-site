Course Description
-------------------
Introduction to Systems Programming introduces students to the foundational concepts and techniques used to build low-level software systems in Unix environments. Students will learn how programs interact  directly with operating systems, hardware, and memory through topics such as processes, memory management, file I/O, signals, threads, interprocess communication, and network programming using the C programming language. The course emphasizes hands-on programming and debugging, giving students practical experience working with system calls, command-line tools, and performance-oriented software development. By the end of the course, students will have a strong understanding of how modern computer systems operate beneath high-level applications and will be prepared for more advanced courses in computer systems. 

Prerequisite: Core Programming (or concurrently)
