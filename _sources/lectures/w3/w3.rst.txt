Week 3: Memory Model and Memory Bugs
====================================

Overview
--------

This week we will complete our tour of pointers and then we will look at where a running
program's memory lives and what goes wrong when we misuse it. We end with
how real C programs are split into files, packaged into libraries, and
built with ``make``.

Topics
------

- Enumerations, and catching non-standard C with ``-pedantic``
- Pointers to pointers and changing a caller's pointer
- Arrays of strings, ``argv``, and 2D arrays (automatic and dynamic)
- ``realloc``, ``memcpy``, ``memmove``, and ``memset``
- A process's virtual address space: text, data, BSS, heap, and stack
- Common memory bugs: uninitialized reads, buffer overflows, use after
  free, bad frees, and leaks
- Finding memory bugs with AddressSanitizer and Valgrind
- Header files, separate compilation, and static and shared libraries
- Makefiles
