Week 6: File I/O
================

This week we open, read, and write our own files using the Unix I/O system
calls, then look at how the C standard I/O library sits on top of them.

Topics
------

- Files as sequences of bytes and the current file position
- File descriptors and the standard streams (0, 1, 2)
- Unix I/O: ``open``, ``read``, ``write``, ``lseek``, and ``close``
- ``open`` flags (``O_RDONLY``, ``O_WRONLY``, ``O_CREAT``, ``O_TRUNC``,
  ``O_APPEND``) and file permissions
- Short counts and how to handle them
- Error handling in practice: ``errno``, ``EFAULT``, and wrapper functions
- How the kernel tracks open files, and I/O redirection with ``dup2``
- File metadata with ``stat``
- Standard I/O: ``FILE *`` streams, ``fopen`` modes, ``fgets``, and choosing
  between standard I/O and Unix I/O
