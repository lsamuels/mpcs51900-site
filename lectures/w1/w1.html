    M1: Introduction to Systems Programming and C Basics¶

    This week we start with why systems programming matters and why C is the language for it. We then cover how a C program goes from source code to a running executable, and move quickly through C syntax. Since you already know how to program, we focus on the places where C differs from languages like Python and Java.

    Topics¶

    • What systems programming is, and what you’ll build this quarter

    • Why C: low-level vs. high-level languages

    • The structure of a C program, compiling with gcc, and what each compilation stage does

    • Compiler warnings: what they mean and why we treat them as bugs

    • Static typing, primitive types, and type sizes

    • Input and output with printf and scanf

    • Operators, control flow, and functions

    • Arrays, structs, typedef, and strings
